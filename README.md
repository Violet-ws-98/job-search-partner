# 求职协作 · Job Search Partner

面向有工作经验的求职者的 AI skill：从真实经历和求职诉求出发，评估岗位、定制简历、练习面试，并根据真实面试反馈继续调整。

这是一个方法与模板包，不是自动投递工具，也不包含任何真实求职者的资料。当前为公开试用版，欢迎反馈。

## 能做什么

- **理解自己**：梳理经历、个人贡献、成果口径、职业动机和工作边界。
- **筛选岗位**：分别评估“能否胜任”和“是否值得选择”，标明信息缺口。
- **定制简历**：突出有依据的优势，按目标岗位调整重点，保留真实事实。
- **模拟面试**：一次一题，先听你的回答，再调整逻辑、表达和个人贡献。
- **口语记忆链**：按你的讲述顺序，把答案压缩成能唤起内容的关键词链。
- **复盘面试**：区分实际提问、口述信息和推断，调整下一轮准备重点。

可以从任何一个模块开始，不需要先填完整套问卷。首次使用需要提供自己的经历、目标岗位或当前问题；skill 不自带你的背景。

## 安装到 Codex

本仓库根目录就是一个完整的 skill 文件夹。将仓库克隆到你的 Codex 技能目录，保持文件夹名为 `job-search-partner`：

```bash
git clone https://github.com/Violet-ws-98/job-search-partner.git "${CODEX_HOME:-$HOME/.codex}/skills/job-search-partner"
```

如果已有同名目录，先检查其中是否有自己的修改，不要直接覆盖。也可以下载仓库 ZIP，解压后将文件夹重命名为 `job-search-partner`，放入同一技能目录。

在能识别该 skill 的会话中使用 `$job-search-partner`。如果当前会话尚未显示新技能，可重新打开会话后再试。其他支持 `SKILL.md` 的工具需按各自的技能安装方式放置，本仓库未逐一验证兼容性。

## 开始使用

**岗位评估**

> 使用 $job-search-partner。我会提供简历和几个岗位描述，请先理解我的求职诉求，再分别评估胜任匹配和选择匹配。缺少信息时明确列出来。

**模拟面试**

> 使用 $job-search-partner，针对这个岗位和我模拟面试。一次问一题，先等我回答，再帮我把表达讲清楚。保留我的口语习惯，最后给一条口语记忆链。

**针对性简历**

> 使用 $job-search-partner，以这份简历为基础，针对这个岗位突出相关经历。先给修改文字，确认后再创建副本。

**面试复盘**

> 使用 $job-search-partner，整理这次面试中实际问到的问题和新了解的业务信息，帮我确定下一轮最值得补充的准备。

## 使用方式与边界

默认不绑定任何外部服务。文件编辑、在线表格同步取决于你所使用的 AI 工具及已授权能力；没有连接器时，可以先在对话或本地文件里完成。它不会自行申请岗位或联系招聘方。

岗位评分是辅助判断，不是录用概率。真实工作边界由你决定；不通过编造经历、数据或意愿提高“匹配度”。

填写后的模板属于个人资料，请另存到私人工作区，**不要提交到本仓库**。公开反馈也请使用虚构或充分去标识的示例，避免上传完整简历、薪资记录、面试录音、内部资料或访问凭据。

## 文件结构

- `SKILL.md`：入口与共同原则。
- `references/`：履历、岗位评分、简历、模拟面试、复盘和交付指南。
- `assets/`：四类空白模板。
- `agents/openai.yaml`：技能显示名称和默认调用提示。

## 如何参与试用

可以在 Issues 中反馈：你尝试的模块、期望行为、实际表现，以及不包含个人信息的最小示例。尤其欢迎指出：问题是否自然、改写是否保留本人语气、记忆链是否方便复述、评分依据是否清楚。

目前已完成格式、文件引用和发布内容检查；不同用户、岗位及工具环境下的实际效果仍需要试用验证。
